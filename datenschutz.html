ClipFinder – Datenschutzerklärung / Privacy Policy

Stand: 9. Oktober 2026

ClipFinder ist ein privat betriebenes Tool des Twitch-Streamers Woitzi. Es läuft auf einem eigenen Server und wird ausschließlich vom Betreiber selbst genutzt, um Clips aus eigenen Stream-Aufnahmen zu erstellen und auf den eigenen Kanälen zu veröffentlichen. Es ist kein öffentlicher Dienst; andere Personen können sich nicht anmelden.

Welche Daten werden verarbeitet?

  • Google/YouTube: Über die YouTube Data API erhält ClipFinder nach ausdrücklicher Freigabe durch den Kontoinhaber das Recht, Videos auf den eigenen YouTube-Kanal hochzuladen (youtube.upload) und den Kanalnamen anzuzeigen (youtube.readonly). Gespeichert wird nur das dafür nötige Zugriffstoken – auf dem eigenen Server des Betreibers.
  • Instagram / TikTok: Entsprechend nur die Zugriffstokens, die zum Veröffentlichen eigener Videos auf den eigenen Konten nötig sind.
  • Hochgeladen werden ausschließlich eigene Videos des Betreibers mit selbst gewählten Titeln und Beschreibungen.

Weitergabe

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt. Daten von Google-APIs werden ausschließlich gemäß der Google API Services User Data Policy einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“) verwendet.

Löschen / Widerruf

Die Verbindung kann jederzeit in ClipFinder getrennt werden; das Token wird dabei gelöscht und bei Google widerrufen. Zusätzlich lässt sich der Zugriff unter https://myaccount.google.com/permissions entziehen.

English summary: ClipFinder is a private, self-hosted tool used only by its owner to upload his own videos to his own YouTube, Instagram and TikTok accounts. Access tokens are stored only on the owner's server, never shared or sold. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in ClipFinder or at https://myaccount.google.com/permissions.
